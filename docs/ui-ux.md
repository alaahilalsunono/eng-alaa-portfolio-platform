## Navigation Structure

The public portfolio will use a single-page layout.

The Home page will contain:

- Hero Section
- About Me
- Skills
- Projects
- Contact

Each project card will open a dedicated Project Details page that contains:

- Project Description
- Project Images
- Technologies Used
- GitHub Link
- Demo Link

The admin area will be separated from the public portfolio and will contain its own management pages.
